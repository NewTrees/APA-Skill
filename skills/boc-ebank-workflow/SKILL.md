# 中国银行企业网银流程开发

从当前流程提炼的中国银行（iGTB Net）企业网银自动化 Skill。提供完整可复制的流程模板（`main.prjp` + 全部 Python 流程块）、配置样例和业务规则说明，用于在 APA 项目中新建、迁移或扩展中行网银流程。

## 何时使用

- 需要新建中国银行企业网银自动化流程（登录、流水、余额、回单、对账单、安全退出）。
- 已有中行流程需要替换登录页面实现、U盾/HUB（新同事 CloudUSB）、密码输入器（KeyBox/新同事）、交付转换或收尾模块。
- 排查或维护中行流程的重试、汇总、密码错误处置等机制。

不适用：跨行转账等写操作、短信/邮件验证码登录、reCAPTCHA 等验证码处理。

## 使用步骤

1. 阅读 [references/architecture.md](references/architecture.md) 了解模块分层（框架编排 / 公共 / 会话 / 业务 / 交付 / 收尾 / 设备）和维护边界。
2. 将 `assets/flow/` 中的 `main.prjp` 和全部 `*.py` 复制到目标 APA 项目根目录（目标项目须为单流程项目）。`main.prjp` 已包含连线结构与未连线维护节点。
3. 将 `assets/res-config/` 中的 `Config.example.xlsx`、`模板/`、`映射/` 复制到目标项目 `res/config/`，按客户环境填写。
4. 按 `assets/docs/需求流程说明文档.md` 第 3、11 章配置平台 Asset `EbankConfig` 与数据队列任务字段。
5. 替换运行方案只改 `配置_运行方案.py` 中的 `use_*` 调用；禁止修改 `框架_*` 文件。
6. 银行页面改版时，按 web-exploration 重新探索并验证入库界面元素后，更新对应 `业务_*` / `会话_*` 流程块引用；界面库是二进制资源，不在本 Skill 中，需在目标项目重新拾取。

## 关键约束

- **密码安全**：一次登录尝试证书密码只输入一次，结果不明确（code=4）时禁止重试，防止 U盾 锁定；密码明文不得进入代码或日志。
- **框架稳定层**：`框架_*` 流程块、`公共_数据契约.py` 既有字段语义、`main.prjp` 既有节点 ID 不许修改；新增节点用全新 UUID。
- **模块契约**：业务/交付/收尾模块必须遵守 `公共_数据契约` 中的 `BusinessResultModel` 等统一契约。
- **网银助手路径**：`ASSISTANT_PATH` 按目标机器实际安装位置调整，见 `配置_运行方案.py`。
